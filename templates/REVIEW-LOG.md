# Review Log

C/M = deduplicated CRITICAL / MAJOR issue counts (see `ISSUES.md` for the per-issue ledger).
Res/Rem/New = previously raised issues resolved / remaining / new (vs. the previous run).
Each run's folder in `../reviewed documents/` holds the reviewed document, the full-review.docx, and `archive/` with the machine-readable sources for Q&A and re-review.
